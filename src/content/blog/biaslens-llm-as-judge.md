[BiasLens](https://github.com/JaspreetSinghA/biaslense) is an open-source toolkit for detecting and mitigating cultural and religious bias in text generated by large language models. I started it in January 2024. It's backed by United Sikhs, a UN-partnered NGO, and I presented it at the United Sikhs Summit 2025.

## The problem

LLMs often get Sikh identity wrong. They mix Sikhism up with other religions, stereotype people by visible articles of faith, or state basic facts incorrectly. Sikhs were largely missing from existing bias benchmarks, so I couldn't measure the problem with off-the-shelf tools.

## Version 1: a rule-based scorer, calibrated against people

The first scorer combined a **five-part rubric** (accuracy, fairness, representation, linguistic balance, cultural framing) with an **embedding-similarity check** against a set of known stereotype phrases.

Hand-tuned weights are guesses, so I calibrated them against human judgment instead:

- Collected **276 human ratings** from **6 raters** on responses from **3 LLMs**.
- Measured inter-rater agreement with **Krippendorff's alpha** to see which rubric dimensions people actually agree on.
- Set the scorer's penalty multipliers and baselines from those agreement results and the raters' score distributions.

## Version 2: a structured LLM-as-judge

Rules and keyword similarity missed subtler cases. I rebuilt the scorer as a **structured LLM-as-judge**: it rates text **1–5 on each of the 5 dimensions** and writes a rationale for each score. Every score comes with its reasoning, so a person can check it.

I validated it on a **hand-labeled benchmark with a held-out test split**. That way I never tuned the prompt on the same examples I reported results on.

## Shipping it

Researchers and developers use different tools, so BiasLens comes in four forms:

- a **Python SDK** on [PyPI](https://pypi.org/project/biaslense/) (`pip install biaslense`)
- a rate-limited **FastAPI REST API**
- a **Streamlit** web app for non-programmers
- an **MCP server**, so AI assistants can call the scorer directly
